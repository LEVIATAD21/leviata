# Direção de Animação — KAWA-AI

## Objetivo

Substituir o loop vetorial atual por uma animação profissional, legível e tecnicamente coerente para demonstrar a operação do KAWA-AI em uma página de projeto ou README. O ativo final será um loop horizontal de 10 segundos, sem áudio, desenhado para comunicar autonomia local, organização de tarefas, memória persistente, segurança e autorregulação de recursos.

## Direção global

| Elemento | Definição aprovada |
|---|---|
| Formato | MP4 leve para uso em página e GIF de prévia quando a conversão preservar legibilidade |
| Proporção | 16:9 horizontal, 1280×720 |
| Duração | 10 segundos em loop contínuo |
| Áudio | Nenhum |
| Estética | Painel técnico elegante, não agressivo; visual de produto local sofisticado |
| Paleta | Azul-marinho quase preto, ciano, verde-água e âmbar discreto em alertas |
| Texto em cena | Nenhum; a animação deve funcionar sem texto pequeno ou código decorativo ilegível |
| Exclusões | Sem robôs humanoides, caveiras, estética de invasão, hologramas genéricos, partículas excessivas, marcas d'água ou logotipos de terceiros |

## Plano de cena

| Tempo | Ação visual | Movimento |

## Referência visual primária

> Crie uma imagem de referência 16:9 para uma animação de interface chamada KAWA-AI. Uma estação de controle técnico minimalista, vista frontal, com um núcleo hexagonal ciano no centro, cinco módulos geométricos equilibrados ao redor e caminhos luminosos conectando-os. Fundo azul-marinho quase preto com grade sutil, verde-água para fluxos confirmados e pequenos sinais âmbar exclusivamente em um medidor de recursos. Estilo de visualização de produto premium, renderização 3D limpa com detalhes vetoriais, iluminação suave e materiais foscos. Sem texto, sem pessoas, sem robôs, sem caveiras, sem código aleatório, sem logotipos, sem marcas d'água, sem anotações.

## Prompt de vídeo para Gemini

> Create a 10-second seamless 16:9 silent motion graphic for KAWA-AI, a local AI orchestration system. Use a premium technical product-visualization style: near-black navy background, restrained cyan and aqua light paths, tiny amber accents only on a resource meter, clean 3D geometric panels with vector-like precision, no text and no logos. The central cyan hexagonal core is visible from the first frame and remains centered throughout. In seconds 0–2 the camera makes a subtle forward move as the core emits one restrained pulse. In seconds 2–5 one abstract task signal enters from the left and divides into five visible paths feeding five balanced modules representing planning, knowledge, security, persistent memory, and local execution; every module remains present and stable. In seconds 5–7 resource bars redistribute between workers and one bar gracefully shrinks to show adaptive memory throttling while the task flow keeps moving forward at a slower pace. In seconds 7–10 a subtle translucent security shield closes around the security module, all paths return to the central core, and the camera gently returns to the initial framing for a seamless loop. No audio, no characters, no hacker imagery, no skulls, no random code, no interface text, no watermarks, no flicker, no abrupt cuts.
